# Cartify Database Seeder Guide

This directory contains database seeding utilities for the Cartify E-commerce application.

### Available Scripts:
- `seed500Products.js`: Seeds **520+ high quality products** across 20 distinct categories and 35 premium brands with verified Unsplash e-commerce image URLs.
- `seed.js`: Original base demo data seeder.

### How to Run:
```bash
cd backend
node seed/seed500Products.js
```
